Fill colors are black for light themes and white for dark themes. Path geometry is unchanged.
The viewBoxes center the artwork and trim excess transparent padding, keeping at least 0.4 units clear around every path. This gives the three icons a consistent visual size within the navigation icon slot.
Page headers use a 30 px icon widget. Navigation rendering retains the cached native Qt icon engine.

The upstream MIT license is included in `LICENSE`. These assets are bundled with the desktop resources; no runtime download is needed.
