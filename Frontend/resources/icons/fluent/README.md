Fill colors are black for light themes and white for dark themes. Path geometry is unchanged.
The viewBoxes center the artwork and trim excess transparent padding, keeping at least 0.4 units clear around every path. This gives the icons a consistent visual size within the navigation icon slot. Task settings use separate artwork from the quick-start navigation.
Page headers use a 30 px icon widget. Navigation rendering retains the cached native Qt icon engine.
